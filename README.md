# ClubHub — Pull Request Party

Welcome to the ClubHub team!

## Workshop goal
Each teammate edits their own section in `team.md`, opens a pull request, gets it reviewed, and merges it.

## Team rules
1. Work on a new branch, not directly on `main`.
2. Use a clear pull request title.
3. Ask a teammate to review before merging.
4. Do not share personal emails, passwords, or tokens in the repository.

**Bonus (only if time permits):** propose an event in `events.md`.
